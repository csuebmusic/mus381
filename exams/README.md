# Exams

The course's two graded written exams, kept in one place so the TA has a single home for both. TA-facing: each file holds the administration notes, the exam itself, and the answer key. The exam section of each file can be copied as the student handout; the answer key stays for grading.

- `terminology-exam.md` — the Module 3 midterm. Cumulative over Modules 1 through 3, mapped one-to-one to the midterm review handout (`module-03-recording/lessons/09-handout-midterm-review.html`). Administered Wed Wk 9, after the sample libraries are submitted.

Weights are set in `course-outline.md` (currently TBD).
