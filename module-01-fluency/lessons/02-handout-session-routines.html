Session Routines

How you start and end every session in the lab.

In this class, you work locally on whichever lab computer you're sitting at, and use the class server to keep your work in sync between sessions. The lab is shared with the Art department, so audio gear lives in storage between sessions and comes out at the start of yours. This card covers both halves of every session: what to do when you arrive (set up gear, download from the server), and what to do before you leave (upload to the server, stow gear). Each half takes a few minutes. Do them every time.

How the workflow works

You always have two copies of your work:

  • Local: at ~/Documents/netid/ on whichever lab computer you're using, where netid is your NetID. This is where you actually work during a session. Local files load fast and are reliable.
  • Server: your own folder on the class server, which you reach with an app called FileZilla. This is the master copy. It's how your work moves between computers.

The pattern is: download from the server at the start, upload to the server at the end. The local copy is where you work; the server is how you transport.

Audio gear lives in the lab's gear storage. At the start of every session you take what today's session needs; at the end you stow it back. The room gets reset for the Art department between our class meetings, so nothing stays at the station.

  • Every session: audio interface and headphones.
  • Recording labs (Day 1 and Module 3): also a dynamic mic, its stand, and an XLR cable.
  • Module 4 (sessions that use MIDI): also a MIDI keyboard.

The day's lab handout will tell you which applies. Headphones always go through the interface, never directly into the computer.

The most important rule

Always upload to the server before you leave. You can reach the server from inside the lab only. Anything you forget to upload stays on that one computer until you are back in the room, and if you sit somewhere else next session you'll be working from an older version.

Start of session

Gear

  1. From the lab's gear storage, take the audio interface and headphones. If today's lab handout calls for it, also take the dynamic mic, mic stand, and XLR cable, or the MIDI keyboard.
  2. Set everything down at your station. Before plugging anything in: turn all interface knobs (gain, main / output, headphone) all the way down (counterclockwise, to zero).
  3. Plug the interface's USB cable into the hub. Plug the headphones into the interface's headphone jack. Slide the in-line headphone slider all the way up. If you brought the mic, set it in its stand and plug the XLR from the mic to input 1 of the interface. If you brought the MIDI keyboard, plug its USB cable into the hub.
  4. Open Audio MIDI Setup (Cmd + Space, type the name, return). Confirm your interface is listed on the left. If it is, right-click it once and choose Use this device for sound input, then right-click again and choose Use this device for sound output. With your interface selected, check that its Format reads 48,000 Hz, the rate this course works at; if it shows a different rate, click the Format dropdown and pick a 48,000 Hz option. (On the UM2, the input and output are separate entries, so check the rate on both.) Quit Audio MIDI Setup (Cmd + Q). If your interface isn't listed, unplug the USB cable from the hub, wait a moment, and plug it back into a different port on the hub.

Connect to the server

  1. Open FileZilla (Cmd + Space, type the name, return).
  2. Fill in the Quickconnect bar across the top of the window:
    • Host: sftp://134.154.190.239
    • Username: your NetID
    • Password: your NetID password, the same one you use for Canvas and campus email
    • Port: 22
    Press Quickconnect.
  3. FileZilla shows a message about an unknown host key. Tick Always trust this host, add this key to the cache, then click OK.
  4. Look at the two halves of the window. The left side is this computer; the right side is the server. You arrive inside your own folder on the server, and everything in it is yours alone.
You type your password every session

FileZilla on the lab computers is set to leave passwords unsaved, so you enter yours at the start of each session. Use the Quickconnect bar rather than the Site Manager.

Download your work

  1. On the left side, navigate to ~/Documents/. If a folder named with your NetID is there, open it. If this is a computer you haven't used before, make one first: in Finder, open Documents, press Cmd + Shift + N, and name it your NetID.
  2. Click into the right side and select everything (Cmd + A), then drag it across into the left side.
  3. If FileZilla asks about files that already exist, choose Overwrite if source newer, tick Always use this action and Apply to current queue only, and click OK.
Seeing what's different

To compare the two sides before you drag anything, choose View → Directory Comparison → Compare modification time, then View → Directory Comparison → Enable. FileZilla colors any file that differs between the two sides and marks any file that exists on one side only.

If you need anything from the shared folder today, get it now, before you disconnect: see Shared files below.

  1. Choose Server → Disconnect, then quit FileZilla (Cmd + Q).

Now you're ready to work. Open Audacity, Ableton, or whatever you're using, and work entirely from your local ~/Documents/netid/ folder.

Shared files

Material from your instructor, and files your classmates post for peer review, live in a folder called public at the top level of the server. From your own folder, click the / at the top of the server's directory tree on the right side, then open public. Download what you need the same way you download your own work, while you're still connected. The day's handout or project prompt names the exact folder.

End of session

Do this before you leave the lab. Every session.

Upload your work

  1. Save your work in whatever app you've been using (Cmd + S).
  2. Open FileZilla and connect again with the Quickconnect bar.
  3. On the left side, open ~/Documents/netid/. On the right side, stay in your own folder on the server.
  4. Click into the left side, select everything (Cmd + A), and drag it across into the right side.
  5. Choose Overwrite if source newer, tick Always use this action, and click OK.
  6. Watch the transfer queue along the bottom of the window. When it empties and your files appear under Successful transfers, the upload is finished.
  7. Choose Server → Disconnect, then quit FileZilla (Cmd + Q).
The overwrite dialog

FileZilla asks what to do whenever a file exists on both sides. Overwrite if source newer is the choice in both directions: downloading, it takes the server's copy when the server is ahead; uploading, it takes today's work over last session's. Always use this action applies your choice to every file in the transfer. Tick Apply to current queue only next to it so the choice stops there rather than applying to your next transfer.

Sign out and quit

  1. Sign out of any browser accounts (Canvas, Google, Microsoft, etc.) and quit your browser (Cmd + Q).
  2. Quit all apps with Cmd + Q. Look at the Dock: any app with a small dot under its icon is still running.

Gear

  1. Turn all interface knobs (gain, main / output, headphone) back to zero.
  2. Unplug the headphones from the interface, the interface's USB from the hub, and the mic's XLR from the interface and from the mic (if you used a mic today). Coil cables loosely; don't kink them.
  3. Return the interface, headphones, and any add-ons you used to the lab's gear storage.
  4. Chair in.
