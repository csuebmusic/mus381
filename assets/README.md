# Assets

Shared resources for the course's student-facing materials.

## contents

- `style.css`: the stylesheet for every student-facing HTML document
- `audio/`: audio demos for readings, generated by the scripts in [`under-the-hood/build/`](../under-the-hood/build/), plus `audio/source/` for the recordings those scripts use
- `images/`: diagrams, screenshots, and photographs, in `module-XX-week-YY/` folders
- `videos/`: short Audacity screen recordings for readings, provided by Inés; specs in [`videos/README.md`](videos/README.md)

Naming, chrome, dates, and the visual system are in [`../under-the-hood/meta/build-conventions.md`](../under-the-hood/meta/build-conventions.md). Per-asset specs are in [`asset-recipes.md`](asset-recipes.md).
