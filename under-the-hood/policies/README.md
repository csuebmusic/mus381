# Policies

Course policies that apply across modules. The instructor carries them out, and the faculty coordinator owns them.

## Contents

- [`server-archival-policy.md`](./server-archival-policy.md): what happens to student working files on the class server over time. Files stay until the faculty coordinator removes them, and the annual summer review clears folders for students who have left or aren't continuing.

## Adding new policies

Each new policy gets its own Markdown file here.
